Downloads the catalog file generated by a job. The [XML structure](../intro/40-xml-struktura.md) chapter describes what the file contains.

## When to call it

When the job has ended successfully and the job status check returned a `fileName`, see the [When a job ends](../intro/30-synchronizace-katalogu.md#when-a-job-ends) section of the guide.

## What to watch out for

- You cannot tell the catalog type from the file name. Go by the `catalogType` you started the job with.
- The catalog file is available for a limited time: assume 24 hours after generation. Generating a new file does not delete the previous one.
- The content of a generated file does not change. Newer data comes only with a new job started with [`POST /products/catalog`](post__products_catalog.md).

## Example

```bash
curl -X GET '{{baseUrl}}/files/pricelist_7_1000001_21052026134339_0d5a33c8-1fac-4272-8ef5-5aeb5c6addfa.ZIP' \
  -H 'Authorization: Bearer {access_token}' \
  -H 'Accept: application/zip, application/octet-stream, */*' \
  --output catalog.zip
```

## Common errors

| Status code | When it occurs                                                                       | What to do                                                                                               |
| ----------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| `400`       | Invalid request.                                                                     | Compare the call with the example.                                                                       |
| `401`       | The token is missing, invalid, or expired.                                           | [Renew the token](../intro/20-autentizace.md#renewing-a-token) or obtain a new one and repeat the call.  |
| `403`       | Invalid call, for example the file name is missing.                                  | Add the `fileName` to the address.                                                                       |
| `404`       | The file was not found, for example because of a wrong name or expired availability. | Check the `fileName`. If the file is no longer available, start a new job.                               |
| `500`       | Internal server error.                                                               | Follow the [Retrying after errors](../intro/30-synchronizace-katalogu.md#retrying-after-errors) section. |
| `503`       | The service is temporarily unavailable.                                              | Follow the [Retrying after errors](../intro/30-synchronizace-katalogu.md#retrying-after-errors) section. |
