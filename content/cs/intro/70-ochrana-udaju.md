# Ochrana osobních údajů

Poslední aktualizace: [datum prvního nasazení]

**1. Sběr dat**\
Tento web je statická dokumentace. Neshromažďujeme, neukládáme ani neodesíláme žádné osobní údaje. Web nepoužívá cookies ani měření návštěvnosti a nenačítá obsah od třetích stran.

**2. Hosting**\
Web je hostován na službě GitHub Pages. Její provozovatel, společnost GitHub, může při návštěvě zaznamenat vaši IP adresu pro účely provozu a zabezpečení služby. K těmto záznamům nemáme přístup. Podrobnosti uvádí prohlášení společnosti GitHub o ochraně osobních údajů.

**3. Nastavení v prohlížeči**\
Volba světlého nebo tmavého režimu a jazyka ukázek kódu se ukládá pouze ve vašem prohlížeči a nikam se neodesílá.

**4. Změny těchto zásad**\
Tyto zásady můžeme čas od času aktualizovat. Změny zveřejníme na této stránce.
