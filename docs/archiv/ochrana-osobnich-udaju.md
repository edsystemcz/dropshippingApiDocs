# Zásady ochrany osobních údajů (archiv)

Text byl na webu jako poslední kapitola úvodu do 2026-11-13; nasazený nebyl nikdy. Web ho nemá, protože odkazy na dokumentaci vedou z eD SHOPu (edshop.edsystem.cz), kde jsou všechny dokumenty (docs/adr/0006). Znění platilo pro web se skrytým tlačítkem „Test Request“, bez měření návštěvnosti, bez obsahu z cizích domén a s úložištěm prohlížeče jen pro barevný režim a jazyk ukázek kódu. Datum zůstalo zástupné, doplnit se mělo při prvním nasazení.

## Česky

````markdown
# Ochrana osobních údajů

Poslední aktualizace: [datum prvního nasazení]

**1. Sběr dat**\
Tento web je statická dokumentace. Neshromažďujeme, neukládáme ani neodesíláme žádné osobní údaje. Web nepoužívá cookies ani měření návštěvnosti a nenačítá obsah od třetích stran.

**2. Hosting**\
Web je hostován na službě GitHub Pages. Její provozovatel, společnost GitHub, může při návštěvě zaznamenat vaši IP adresu pro účely provozu a zabezpečení služby. K těmto záznamům nemáme přístup. Podrobnosti uvádí prohlášení společnosti GitHub o ochraně osobních údajů.

**3. Nastavení v prohlížeči**\
Volba světlého nebo tmavého režimu a jazyka ukázek kódu se ukládá pouze ve vašem prohlížeči a nikam se neodesílá.

**4. Změny těchto zásad**\
Tyto zásady můžeme čas od času aktualizovat. Změny zveřejníme na této stránce.

**5. Kontakt**\
Máte-li dotazy k těmto zásadám, založte prosím issue v našem GitHub repozitáři: https://github.com/edsystemcz/dropshippingApiDocs/issues
````

## English

````markdown
# Privacy policy

Last updated: [date of first deployment]

**1. Data collection**\
This website is static documentation. We do not collect, store or transmit any personal data. The website does not use cookies or visitor analytics and does not load content from third parties.

**2. Hosting**\
The website is hosted on GitHub Pages. Its operator, GitHub, may record your IP address when you visit, for the purposes of operating and securing the service. We have no access to these records. Details are provided in GitHub's privacy statement.

**3. Browser settings**\
Your choice of light or dark mode and of the code sample language is stored only in your browser and is not sent anywhere.

**4. Changes to this policy**\
We may update this policy from time to time. We will publish any changes on this page.

**5. Contact**\
If you have questions about this policy, please open an issue in our GitHub repository: https://github.com/edsystemcz/dropshippingApiDocs/issues
````
